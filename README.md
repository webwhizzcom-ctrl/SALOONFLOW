# SalonFlow — Salon Management & Billing System

SalonFlow is a modern salon operations platform built for real-world salon workflow management.
Designed specifically for salons, beauty studios, PMU clinics, and hair treatment centers, the system focuses on speed, simplicity, billing efficiency, and staff role security.

Built for:
**ASMITA'S BEAUTY SALON & ACADEMY | PMU CLINIC**

---

## Features

### Appointment Management

* Unified appointment timeline
* Shared appointment visibility for all staff
* Receptionist/Admin appointment controls
* Appointment deletion with permission checks
* Responsive salon scheduling workflow

### Billing System

* Fast salon billing workflow
* Fixed ₹ amount discounts
* Percentage discounts
* Multi-service invoice generation
* WhatsApp billing message generator
* Receipt printing & PDF download
* INR currency formatting throughout

### Customer Management

* Quick customer creation
* Customer search system
* Phone-based lookup
* Simplified customer records
* Fast operational workflow

### Staff & Permissions

Role-based secure access system:

* Admin
* Receptionist
* Senior Staff
* Junior Staff

Features:

* Session protection
* Hidden admin financials
* Restricted dashboard access
* Staff view-only appointment permissions

### Reports & Export

* End-of-day Excel reports
* Appointment export
* Payment reports
* Revenue summaries
* Admin-only financial visibility

### UI/UX

* Responsive tablet-first interface
* Clean operational dashboard
* Modern glassmorphism design
* Touch-friendly controls
* Minimal clutter workflow
